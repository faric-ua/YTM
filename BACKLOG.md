
# YTM Importer — Roadmap

## Найближчі покращення

1. **Якість автоматичного пошуку**
   - [x] пріоритет Topic / VEVO / official / artist channel;
   - [x] точніше зіставлення remix / edit / original / extended / club / vocal;
   - [x] штрафи для live / cover / karaoke / reaction / slowed / sped / nightcore;
   - [x] коректна робота з діакритикою: Tiësto → Tiesto;
   - [x] більше кандидатів у межах одного search-запиту;
   - [x] локальний кеш пошуків, щоб не витрачати API-квоту повторно;
   - [ ] тестування пошуку на кількох великих trance-плейлистах.

2. **Вибір приватності плейліста**
   - Private / Unlisted / Public перед створенням.

3. **Нормальне відкриття у YouTube Music**
   - окремий зрозумілий екран після створення;
   - кнопки «Відкрити в YTM» та «Скопіювати посилання».

4. **Ручна заміна треку**
   - список кандидатів;
   - прослуховування/відкриття;
   - вибір правильного результату.

5. **Журнал замін**
   - Original → Replacement;
   - готовий текст для коментарів TikTok.

6. **Вставка списку без CSV**
   - Artist — Track;
   - багаторядковий текст прямо в застосунку.

7. **Історія імпортів**
   - які плейлісти вже створені;
   - дата, кількість треків, пропуски/заміни.

8. **Polish / version 1.0**
   - іконка;
   - стабільна release-збірка;
   - нормальні повідомлення про помилки;
   - фінальне тестування.

## Окремий напрям

9. **Повний редизайн UI/UX**
   - сучасний екран замість горизонтального ряду кнопок;
   - покроковий flow імпорту;
   - кращий список треків і статусів;
   - progress/result screen;
   - Material 3.
