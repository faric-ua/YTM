# YTM Importer v1.4.5 — Compact Review + Better Dialog Actions

## Quota dialog

New action layout:

```text
[          Google Cloud          ]
[       Queue       ][   Close   ]
```

This keeps `Google Cloud` on one line.

## Review screen

Controls between summary and tracks are reduced from four rows to two:

```text
[ ▣ Save ][ ↗ Share ][ ↻ Search ]
[ ≡ All ][ ! Review ][ ✓ Ready ][ × Problems ]
```

## Project save filename

The Android save field now starts with the human playlist name, for example:

`This week's Top 10 Trance Tunes (Aug 17-21, 2026).ytm.json`
