# YTM Importer v1.4.38-R1

- versionName: **1.4.38-R1**
- versionCode: **73**
- status: **NOT PHONE-TESTED YET**
- scope: **two targeted phone regressions only**

## Fix 1 — multi-select checkbox alignment

Real-phone v1.4.38 evidence showed the selective-export checkbox too close to the left card edge.

R1 implementation:

- checkbox uses its own fixed-width touch column;
- checkbox itself is centered inside that column;
- playlist text is rendered in a separate content column;
- tapping the whole row still toggles selection;
- selection counter and multi-select behavior are unchanged.

## Fix 2 — Restore confirmation survives rotation

Real-phone v1.4.38 reproduced:

1. choose a valid `YTM_Backup_*.json`;
2. wait for the Restore information/confirmation dialog;
3. rotate the phone;
4. dialog disappears and the file must be selected again.

R1 implementation:

- validated pending backup is copied into app cache;
- pending-confirmation state is stored in `onSaveInstanceState`;
- recreated `DataActivity` re-inspects the cached backup and reopens the confirmation;
- Cancel / Restore clears the temporary cache file;
- the backup payload itself is not placed into the Bundle.

## Phone acceptance

R1 is accepted only after both pass on a real phone:

1. selective-export checkbox is visually centered relative to its left touch column;
2. Restore confirmation remains present after portrait ↔ landscape rotation without choosing the file again.

No other v1.4.38 behavior is claimed fixed by this R1 build.
