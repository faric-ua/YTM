# Діаграми YTM Importer

GitHub автоматично рендерить Mermaid-код у `.md` файлах.

Актуальні файли:

- `CURRENT_FLOW.md` — вся логіка v0.8.0;
- `ARCHITECTURE.md` — модулі і джерела даних;
- `TRACK_STATE_FLOW.md` — стани одного треку;
- `BEFORE_AFTER_v0.7.1.md` — hotfix кандидатів;
- `BEFORE_AFTER_v0.8.0.md` — імпорт із тексту: було / стало.

Для PNG/SVG скопіюйте блок `mermaid` у Mermaid Live Editor.
