# Навчальний roadmap

Поточна папка — foundation, а не завершений курс.

Наступні розділи варто додавати поступово, використовуючи реальний код і release history.

## План

- `06_ANDROID_PROJECT_SETUP.md` — структура Android/Kotlin проєкту;
- `07_IMPORT_AND_PROJECT_FORMAT.md` — імпорт та YTM Project;
- `08_GOOGLE_YOUTUBE_AUTH.md` — авторизація, session state, recovery;
- `09_YOUTUBE_API_AND_QUOTA.md` — API requests, quota, failure modes;
- `10_SEARCH_AND_EXACT_VIDEO_ID.md` — пошук vs exact identifiers;
- `11_DESTINATION_AND_DUPLICATES.md` — existing playlist, duplicate scan, write plan;
- `12_PENDING_QUEUE_AND_RECOVERY.md` — відкладені операції;
- `13_BACKUP_AND_EXPORT.md` — local backup, account bulk export, manifest;
- `14_THEME_SYSTEM.md` — palette, semantic colors, Accent Card System;
- `15_GITHUB_ACTIONS_RELEASE.md` — signed APK, checksum, artifact;
- `16_BUILD_A_FEATURE_FROM_ZERO.md` — повний практичний feature exercise;
- `17_RECREATE_YTM_IMPORTER.md` — фінальний покроковий прохід від чистого repo.

## Правило розвитку tutorial

Новий навчальний розділ повинен:

1. посилатися на реальний код/реліз;
2. пояснювати проблему до рішення;
3. показувати рішення;
4. містити перевірку результату;
5. описувати failure modes;
6. не переписувати історію заднім числом.
