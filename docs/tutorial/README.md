# YTM Importer — навчальний маршрут

Ця папка перетворює реальну історію YTM Importer на покроковий навчальний матеріал.

Мета — не просто показати готовий код, а відтворити **підхід до створення продукту**:

1. сформулювати задачу;
2. зробити мінімальний робочий вертикальний сценарій;
3. винести відповідальності в окремі компоненти;
4. додати безпечний workflow;
5. будувати APK через CI;
6. перевіряти на реальному телефоні;
7. зберігати докази;
8. документувати не лише успіхи, а й помилки та причини рішень.

## Для кого

- для автора проєкту, щоб через місяці або роки відтворити весь шлях;
- для розробника, який хоче зрозуміти Android/Kotlin-проєкт через реальний кейс;
- для людини, яка хоче побачити практичний цикл `ідея → код → build → телефон → QA → документація`;
- для тих, хто працює з ChatGPT як із технічним партнером, але хоче зберігати контроль через Git, тести та evidence.

## Два шари документації

У проєкті навмисно існують два різні шари.

### 1. Історичний / доказовий

`docs/v.X.Y.Z/qa/`, release docs, bug register, changelog, evidence.

Цей шар не треба «прикрасити заднім числом». Він показує, що реально відбувалося.

### 2. Навчальний

`docs/tutorial/`

Тут історія очищається від зайвого шуму й перетворюється на послідовний урок.

Навчальний шар **спирається** на історичний, але не замінює його.
