# 00 — Почати тут

## Що ми будуємо насправді

YTM Importer — це не лише застосунок для перенесення треків.

Для навчання він є прикладом того, як будувати невеликий реальний продукт, у якому одночасно є:

- Android UI;
- Kotlin;
- Google/YouTube авторизація;
- зовнішній API;
- квоти;
- локальний стан;
- імпорт/експорт файлів;
- черга відкладених операцій;
- історія;
- резервні копії;
- CI/CD через GitHub Actions;
- тестування на реальному пристрої;
- release documentation.

## Головний принцип

Не починайте з питання:

> «Який код треба написати?»

Починайте з:

> «Який завершений сценарій користувач має пройти від початку до кінця?»

Для YTM Importer базовий сценарій став чотирикроковим:

1. Імпорт.
2. Google / YTM.
3. Знайти / перевірити.
4. Створити / додати.

Ця структура пізніше стала не лише UI, а й способом розділити архітектуру.

## Як використовувати цей курс

Для кожного розділу:

1. прочитайте мету;
2. подивіться, який реальний файл/реліз це демонструє;
3. відтворіть логіку самостійно;
4. тільки після цього дивіться готову реалізацію;
5. перевірте результат на реальному пристрої;
6. зафіксуйте evidence;
7. запишіть, що ви дізналися.

## Не плутати три види «готово»

### Код написаний

Файл компілюється або виглядає правильно.

### Build пройшов

CI зібрав APK.

### Функція перевірена

Реальна поведінка підтверджена на телефоні конкретним тестом/evidence.

У цьому проєкті ці стани навмисно розділяються.
