# YTM Importer v0.11.0 — Історія операцій (History / Jobs)

## Головна мета

Зберігати результат кожного створення/додавання плейлиста локально,
щоб користувач міг повернутися до нього після нового імпорту або перезапуску програми.

## Реалізовано

- кнопка `Історія`;
- локальне збереження до 100 останніх операцій;
- статуси:
  - `завершено`;
  - `частково / очікує продовження`;
  - `очікує квоти`;
  - `помилка`;
- дата і час;
- джерело: файл / вставлений текст;
- назва та ID плейлиста;
- Google account;
- YouTube/YTM channel;
- новий / існуючий плейлист;
- кількість:
  - імпортовано;
  - для запису;
  - додано;
  - помилок;
  - очікує;
  - пропущено;
  - не знайдено;
- відкриття старого плейлиста в YTM;
- копіювання посилання;
- копіювання підсумку;
- історичний журнал замін/проблем;
- видалення одного запису;
- очищення всієї історії;
- зв'язок History з Pending Queue (чергою).

## Сумісність

Pending jobs (завдання в черзі), створені v0.10.x, читаються з fallback
(запасними значеннями), навіть якщо в них ще немає нових полів v0.11.0.
