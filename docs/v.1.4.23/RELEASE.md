# YTM Importer v1.4.23 — Button Fit + Home Polish

## Goal

Fix the real-phone text-fit issue found in v1.4.22 without changing app behavior.

## Changes

- compact Home utility buttons are forced to a single line;
- utility labels use a smaller adaptive range;
- compact icons are reduced further;
- top workflow actions get more usable text width;
- top workflow icon/text spacing is reduced;
- Home row gaps/padding are tightened slightly;
- all existing Neon / Blue / Green theme behavior remains unchanged.

## Expected visual result

`Історія`, `Черга`, `Квота`, `Ще` should stay on one line.

The four workflow buttons remain at most two lines, but text should no longer feel squeezed.
