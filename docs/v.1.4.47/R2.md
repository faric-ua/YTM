## Phone findings from R1

Real-phone screenshots on v1.4.47-R1 showed:
- Home hierarchy is directionally correct, but the lower dashboard is still too tall in portrait;
- `Поточний плейлист` and `Швидкі дії` use external headings, which waste vertical space;
- bottom Home navigation has square outer corners;
- selecting `Меню → Тема` closes MenuActivity first, so the theme picker is then shown by MainActivity over Home.

## R2 Home compaction

R2 keeps the approved R1 hierarchy and all existing Neon / Blue / Green palettes.

Changes:
- `Поточний плейлист` heading moves inside the existing interactive playlist card via its eyebrow line;
- playlist action copy shortens to `Натисніть для керування →`;
- `Швидкі дії` moves into a compact accent section container;
- quick-action buttons shrink from 64dp to 58dp;
- section-title bottom spacing is reduced from 8dp to 5dp;
- Home section margins are tightened;
- bottom navigation uses rounded 16dp outer corners plus 8dp side/bottom margins.

## Theme picker ownership

Theme selection now remains inside MenuActivity:
- tapping `Тема` no longer finishes MenuActivity;
- the picker opens over Menu, not Home;
- selecting a different theme updates the saved style and recreates MenuActivity;
- Menu stays the visible parent after theme change.

The old MainActivity ACTION_THEME bridge remains as a compatibility path but is no longer the normal Menu flow.

## Copy cleanup

The no-target message:
`Спочатку створіть або виберіть плейлист`

is shortened to:
`Створіть / виберіть плейлист`

for both Open-in-YTM and Copy-link fallback paths.

## Safety

- no auth/search/write behavior is intentionally changed;
- R1 Playlist-Hub navigation, modal theme, and rotation fixes remain intact;
- versionCode advances to 89 so R2 can install cleanly over R1 code 88.
