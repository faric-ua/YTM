## Scope

R3 consolidates three corrective waves found during v1.4.47/R1/R2 QA.

### Wave 1 — modal lifecycle continuity

Fixes the remaining rotation-state gaps for:
- ListSelector Help windows;
- RecentFileChooser Help;
- StorageChooser Help;
- Review `Поточний YTM Project` action modal;
- Menu-owned Theme picker.

Contract:
- rotation recreates the same open modal over the same parent screen;
- no Save / Share / theme-change / other action runs automatically;
- Close/Back leaves the user on the same parent;
- no duplicate dialog after repeated rotation.

Wave commit:
`dd7e8d5e984200b9c2cdca993bc8378a2db4198b`

### Wave 2 — BUG-004 HTTP 401 silent recovery + one retry

Recovery contract:
1. YouTube/Google request returns HTTP 401.
2. The rejected access token is cleared from Google Identity token cache.
3. Google `AuthorizationClient` is asked silently for a replacement token using already-granted scopes.
4. If Google returns a token without interactive resolution, process-memory auth state is updated.
5. The exact original HTTP request is retried **once**.
6. If silent recovery cannot produce a token, requires resolution, or the retry also fails with 401, the existing disconnected/manual-auth fallback remains authoritative.

Security:
- raw OAuth access tokens remain process-memory-only;
- no refresh token is persisted by YTM Importer;
- no OAuth token is added to backup, project, SavedInstanceState, or preferences.

Wave commit:
`f53fc1d3ad8a02c67269c9f22df8e4cc8b2f2f14`

### Wave 3 — BUG-021 History result semantics

History no longer uses one unconditional `Додано X/Y` line for every kind of record.

Primary result wording:
- real YTM write → `Додано в YTM: X/Y`;
- clean completed local import → `Імпортовано: N треків`;
- clean completed restore-like record → `Відновлено: N треків`;
- failed/pending/non-completed remote write keeps the YTM-write result while errors,
  pending counts, skips, duplicates and missing items remain separate lines.

The existing History JSON schema is preserved. No stored History migration is required.

Wave commit:
`e1fee8ed989acfd1209e53873910bf3f362e5ec0`
