
# Portable Assistant Project Skeleton

Copy this directory into a new project and replace placeholders.

The reusable parts are:

- assistant startup/recovery contract;
- system behavior contract;
- release documentation contract;
- test diagram standard;
- release/QA templates.

Do not copy YTM business assumptions into an unrelated project.

The migration ZIP also contains YTM audit scripts under a reference directory.
Those scripts are examples of how contracts were enforced; adapt them rather
than blindly running YTM-specific string assertions in another project.
