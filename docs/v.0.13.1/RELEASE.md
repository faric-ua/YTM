# YTM Importer v0.13.1 — Hotfix меню Дані

## Проблема у v0.13.0

У діалозі `Дані` одночасно використовувалися:

- `AlertDialog.setMessage(...)`;
- `AlertDialog.setItems(...)`.

На Android це призвело до того, що текст повідомлення показувався,
а список дій міг не відобразитися взагалі.

На екрані користувач бачив лише пояснення і кнопку `Закрити`.

## Виправлення

Меню `Дані` тепер має власний layout:

- коротке пояснення зверху;
- окремий `ListView` зі всіма діями.

## Додаткове покращення

Кожна дія тепер має коротке пояснення:

- `Історія → TXT` — читабельний звіт;
- `Історія → JSON` — технічний експорт історії;
- `Черга → JSON` — технічний експорт черги;
- `Повний backup → JSON` — файл для повного Restore;
- `Restore повного backup` — відновлення локальних даних.

Окремо пояснюється, що History JSON не є повним backup.
