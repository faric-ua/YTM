# YTM Importer v1.4.42-R1 — Direct Download via All files access

- versionName: **1.4.42-R1**
- versionCode: **81**
- status: **NOT PHONE-TESTED YET**
- focus: **BUG-012 corrective build**

## Why R1 exists

v1.4.42 phone QA confirmed that the new YTM Importer file selector opens, but Android
11+ blocks `ACTION_OPEN_DOCUMENT_TREE` access to the root `Download` directory.

The project owner explicitly chose the Android **All files access** path so YTM Importer
can read Download directly and show newest files first.

## R1 behavior

On Android 11+:

1. `Home → 1. Імпорт → імпортувати файл`
2. YTM Importer opens RecentFileChooserActivity.
3. If All files access is not enabled, the primary action is:
   `Надати доступ до всіх файлів`.
4. YTM Importer first shows an in-app rationale.
5. `Відкрити налаштування` opens the Android special-access screen for this app.
6. After the user enables the toggle and returns, YTM Importer reads
   `/storage/emulated/0/Download` directly.
7. Matching files are sorted by `lastModified` descending.

Fallbacks remain:
- `Додати SAF-папку…`;
- `Системний вибір файла…`;
- Cancel / Back.

## Security / distribution note

The permission is broad and user-controlled. The app does not enable it silently.

This GitHub/sideload build can use it directly. If the project is later distributed
through Google Play, MANAGE_EXTERNAL_STORAGE has restricted-policy requirements and
must be justified/declared separately.

## Phone acceptance

### A. Grant flow

Path:
`Home → 1. Імпорт → імпортувати файл → Надати доступ до всіх файлів`

Expected:
- rationale appears;
- `Відкрити налаштування` opens Android special access for YTM Importer;
- user enables the All files access toggle;
- Back returns to YTM Importer selector;
- permission button disappears or no longer blocks Download listing.

### B. Download newest-first

Expected:
- files from Download appear without selecting Download through SAF;
- recent House Dance files are visible;
- newer modified timestamps are above older timestamps;
- TXT/CSV/JSON Import filtering still applies.

### C. Direct import

Tap a recent House Dance TXT.

Expected:
- normal import succeeds;
- title remains `House Dance Hit 2000 Vol.1`;
- no Search API call is required.

### D. JSON Restore selector

Path:
`Menu → Дані та резервні копії → Restore → Вибрати backup`

Expected:
- same selector;
- direct Download JSON files are visible;
- selecting one opens the existing Restore confirmation;
- Cancel leaves data unchanged.

### E. Fallbacks

- `Додати SAF-папку…` still opens folder-tree SAF.
- `Системний вибір файла…` still opens Android picker.
- Back/Cancel do not import anything.
