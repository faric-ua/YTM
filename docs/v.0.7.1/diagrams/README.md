# Діаграми YTM Importer

GitHub автоматично рендерить Mermaid-код у `.md` файлах як справжні діаграми.

Файли:
- `CURRENT_FLOW.md` — повна поточна логіка;
- `ARCHITECTURE.md` — модулі;
- `TRACK_STATE_FLOW.md` — стани одного треку;
- `BEFORE_AFTER_v0.7.1.md` — було/стало для hotfix.

Для PNG/SVG:
1. відкрий `.md`;
2. скопіюй вміст між ```mermaid ... ```;
3. встав у Mermaid Live Editor;
4. Export → PNG або SVG.
