# YTM Importer — Документація за версіями

```text
docs/
├── v.0.7.1/
├── v.0.8.0/
└── v.0.9.0/
```

Для кожної версії є окремий snapshot (знімок документації).

Поточна версія:

`docs/v.0.9.0/`

Правило на майбутнє:
кожна нова збірка отримує свою папку `docs/v.X.Y.Z/`,
а попередні папки не перезаписуються.
