# YTM Importer — Documentation convention

Current: `docs/v.1.4.16/`

Current QA: `qa/`

From v1.4.15 every release also includes an immutable QA snapshot:
`docs/v.X.Y.Z/qa/`

Files:
- MASTER_TEST_PLAN.md
- RELEASE_TEST_PLAN.md
- TEST_RUN_TEMPLATE.md
- TEST_DATA.md
- BUG_REGISTER.md

Release architecture diagrams live under:
`docs/v.X.Y.Z/diagrams/`
