# YTM Importer v0.15.2 — Manual URL metadata hotfix

## Проблема

Коли користувач вручну вставляв YouTube / YouTube Music URL,
застосунок зберігав правильний `videoId`, тому в YTM додавався правильний трек.

Але локально в Track було:

```text
selectedTitle = "Ручне посилання"
selectedChannel = "YouTube"
```

Через це список у застосунку не показував фактичну назву заміни.

## Виправлення

Після вставки URL:

1. витягується `videoId`;
2. виконується `videos.list(part=snippet&id=...)`;
3. з YouTube отримуються:
   - реальна назва відео;
   - назва каналу;
4. ці дані записуються в `selectedTitle` / `selectedChannel`;
5. ручна заміна показується як основна назва в локальному списку;
6. оригінальний трек не стирається — він показується нижче як
   `Заміна для: ...` і зберігається в History / replacement log.

## Чому оригінал не перезаписується

Оригінальна назва потрібна для аудиту:

```text
Оригінал → Фактична заміна
```

Тому ми не змінюємо `originalArtist` / `originalTitle`,
а оновлюємо вибраний результат.

## Fallback

Якщо YouTube metadata API не відповів, `videoId` все одно зберігається,
щоб користувач міг додати вручну вибране відео.
