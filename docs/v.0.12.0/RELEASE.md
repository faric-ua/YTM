# YTM Importer v0.12.0 — Дублікати в існуючих плейлистах

## Головна мета

Перед додаванням треків до існуючого YouTube/YTM плейлиста
застосунок тепер читає його вміст і порівнює `videoId`.

## Реалізовано

- `playlistItems.list` для читання існуючого плейлиста;
- пагінація по 50 елементів;
- точне порівняння за YouTube `videoId`;
- окремо рахується:
  - трек уже є в цільовому плейлисті;
  - однаковий `videoId` повторюється всередині поточного імпорту;
- користувач обирає:
  - `Пропустити дублікати`;
  - `Додати все одно`;
- при пропуску:
  - write-запит не виконується;
  - трек отримує статус `DUPLICATE`;
  - у UI видно `⧉ дублікат`;
  - History зберігає кількість дублікатів;
  - журнал замін/проблем містить дублікат;
- показується приблизна економія write quota;
- якщо перевірка дублікатів не вдалася:
  - можна скасувати;
  - або продовжити без перевірки.

## Важливо

Перевірка виконується за точним `videoId`.
Схожість назв треків не використовується, тому програма не буде
помилково вважати іншу версію пісні дублікатом тільки через схожу назву.
