# YTM Importer v1.4.24 — Theme Wave 2

## Goal

Extend the Neon / Blue / Green theme system beyond Home so the app feels like one product.

## Screens included

- Import
- Review
- Destination / create-add flow
- History
- Pending Queue
- Data / Backup
- Service and its nested pages

## Visual rules

- window/system bars follow the selected theme;
- screen backgrounds use the selected theme background;
- cards use themed surfaces and borders;
- primary actions use the theme accent;
- secondary actions use themed neutral surfaces;
- warning/success/error states use semantic palette colors;
- search/input/list surfaces no longer remain fixed graphite where Wave 2 touches them;
- existing functional behavior is preserved.
