# YTM Importer v0.10.1 — Компактний головний екран (Compact main screen)

## Причина

У v0.10.0 постійні блоки:

- Google account / YouTube channel;
- Quota (квота API);

займали значну частину вертикального простору. Через це список треків отримував менше половини екрана на деяких телефонах.

## Зміна

Інформація акаунта та квоти більше **не показується постійними великими блоками**.

На головному екрані залишаються компактні кнопки:

- `2. Акаунт`;
- `Квота`;
- `Черга`.

Стан акаунта коротко видно прямо в кнопці:

- `2. Акаунт` — не підключено;
- `2. Акаунт …` — завантаження;
- `2. Акаунт ✓` — акаунт/канал визначено.

Якщо була quota error (помилка квоти), кнопка показує:

`Квота ⚠`

Повні дані відкриваються тільки тоді, коли вони потрібні:

- натискання `2. Акаунт`;
- натискання `Квота`;
- підтвердження створення/додавання плейлиста;
- Resume (продовження) із Черги.

## Результат

Основна вертикальна площа повертається списку треків.
Функціональність v0.10.0 не видалена.
