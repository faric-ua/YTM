# YTM Importer v0.9.0 — Акаунт і місце призначення

## Головна мета версії

Користувач тепер бачить, **який Google акаунт** і **який YouTube/YouTube Music канал**
використовуються, а перед записом може вибрати:

- створити новий плейлист;
- додати треки до вже існуючого плейлиста.

## Реалізовано

- картка Google акаунта: ім'я + email;
- картка YouTube/YTM профілю: назва каналу + Channel ID (ID каналу);
- кнопка «Змінити акаунт» через account picker (вибір Google акаунта);
- `channels.list(mine=true)` для визначення поточного YouTube каналу;
- `playlists.list(mine=true)` для завантаження власних плейлистів;
- пошук існуючого плейлиста за назвою;
- показ кількості треків і приватності;
- підтвердження target (місця призначення) перед додаванням;
- додавання знайдених треків у кінець існуючого плейлиста.

## Ще не реалізовано в цій версії

- автоматичне виявлення дублікатів;
- Quota Planner (планувальник квоти);
- Pending Queue (черга невиконаних треків);
- Resume (продовження недоробленого плейлиста).

Це наступні етапи roadmap (плану розвитку).
