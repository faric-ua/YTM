# YTM Importer v1.4.21 — Theme System Wave 1

## Goal
Introduce a reusable visual system before styling the remaining screens.

## Themes
- **Neon Dark** — graphite surfaces with pink/red accents.
- **Blue Dark** — deep navy surfaces with electric-blue accents.
- **Green Dark** — dark green surfaces with emerald accents.

The selected theme is stored locally and survives app restart/update.

## Wave 1
- Home
- Import
- Review
- main track cards
- custom UiChrome dialogs

## Decorative contour language
Cards/buttons can use short theme-colored contour strokes on opposite corners and edges, inspired by hand-drawn automotive outline graphics.
