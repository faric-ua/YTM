# 14. Дані та локальні резервні копії
<a id="sec14"></a>
*Локальна повна резервна копія та резервна копія бібліотеки акаунта — різні формати з різними задачами.*

## Повна резервна копія
<a id="sec14a"></a>
Меню → «Дані» → «Повна резервна копія». Файл `YTM_Backup_*.json` зберігає Історію, Чергу, поточний робочий список, кеш пошуку та кеш знімків за URL. Лічильники квоти додаються для діагностики, але під час відновлення не застосовуються. Файл має перевірку цілісності SHA-256.

## Відновлення повної резервної копії
<a id="sec14b"></a>
Відновлення замінює локальні Історію, Чергу, робочий список і кеші, але не змінює віддалені плейлисти YouTube/YTM та не відкочує локальну оцінку квоти. Перед відновленням автоматично створюється страхувальний знімок поточного стану.

## Відновлення лише історії
<a id="sec14c"></a>
«Відновити лише історію» приймає `YTM_History_*.json` і замінює тільки Історію. Черга, квота, кеш пошуку та поточний робочий список не змінюються. Перед імпортом також створюється страхувальний знімок повного локального стану.

## Відкат останнього відновлення
<a id="sec14d"></a>
Якщо відновлення або імпорт Історії дали небажаний результат, можна повернути локальний стан зі страхувального знімка. Квота залишається поточною, а YouTube/YTM не змінюється. Знімок можна окремо видалити, після чого цей відкат стане неможливим.

## Експорт і поширення
<a id="sec14e"></a>
| Дія | Формат |
| --- | --- |
| Історія TXT | Людинозрозумілий звіт. |
| Історія JSON | Технічний експорт Історії, придатний до відновлення. |
| Черга → JSON | Технічний експорт Черги незавершених операцій. |
| Поділитися Історією TXT | Системне меню «Поділитися» Android. |
| Поділитися повною резервною копією | Системне меню «Поділитися» Android після попередження про чутливі дані. |

# 15. Резервна копія бібліотеки YouTube/YTM акаунта
<a id="sec15"></a>
Це інша система, ніж «Повна локальна копія» в розділі «Дані». Тут структура віддаленої бібліотеки акаунта зберігається як папка з файлами Проєкту YTM та `manifest.json`.

## Вибірковий і повний експорт
<a id="sec15a"></a>
- «Вибрати плейлисти для експорту» — вибрати один або кілька плейлистів.
- «Експортувати всі плейлисти в папку» — зберегти всю доступну бібліотеку акаунта.
- Експорт працює лише на читання: YouTube/YTM не змінюється.
- У папці створюються файли Проєкту YTM та manifest.json з індексом.

## Відкрити резервну копію / manifest.json
<a id="sec15b"></a>
YTM Importer читає маніфест локально, показує знайдені файли Проєкту YTM й дозволяє відкрити один плейлист як локальний робочий список без YouTube API.

## Інкрементна резервна копія
<a id="sec15c"></a>
«Оновити резервну копію (інкрементно)» використовує попередню сесію резервної копії як базовий стан, читає поточні плейлисти й класифікує їх за системними станами `NEW / UPDATED / UNCHANGED / MISSING` (новий / оновлений / без змін / відсутній). Попередня резервна копія не змінюється й не видаляється; створюється нова дельта-папка.

Попередня перевірка окремо показує режим «УСІ/ВИБРАНІ», кількість плейлистів і оцінку кількості системних запитів `playlistItems.list`. Для цього сценарію пошук і запис у YouTube/YTM не виконуються: застосунок лише читає віддалений вміст.

## Зібрати повну резервну копію з ланцюжка
<a id="sec15d"></a>
Застосунок сканує локальні сесії резервних копій, знаходить кінцеві точки дельта-ланцюжків, відновлює логічний стан ланцюжка і створює нову самодостатню повну резервну копію. Ця операція локальна: викликів API YouTube немає, вихідні папки не змінюються.

> **Дельта ≠ Повна копія**  
> Якщо ви відкрили маніфест інкрементальної дельта-копії, застосунок прямо попередить, що це не повний експорт. Для самодостатнього стану використайте «Зібрати повну резервну копію з ланцюжка».

# 16. Файли, папки та Android-дозволи
<a id="sec16"></a>
## Список останніх файлів
<a id="sec16a"></a>
YTM Importer має власний екран «Останні файли» перед системним вибором файла Android. Він може показувати файли з папки «Download» («Завантаження») і з папок, до яких ви раніше надали доступ через SAF.

> **ПОТОЧНА ГІЛКА #54**  
> Для повного відновлення та імпорту Історії актуальна гілка вміє перевіряти вміст JSON у фоні й показувати в основному списку тільки файли потрібного типу. Тип визначається за структурою та полем `format` усередині файла, а не лише за назвою або розширенням `.json`. «Інший файл…» залишається резервним способом для старих або зовнішніх файлів.

| Кнопка | Для чого |
| --- | --- |
| Надати доступ до всіх файлів | На Android 11+ дозволяє напряму читати папку «Download» («Завантаження») і автоматично сортувати знайдені файли за датою останньої зміни. |
| Додати папку… | Додати окрему кореневу папку SAF через системний вибір папки. |
| Інший файл… / Системний вибір… | Відкрити стандартний системний вибір файла Android як резервний спосіб. |
| Скасувати | Повернутися без вибору файла. |

## Вибір папки для збереження
<a id="sec16b"></a>
Для збереження/експорту використовується окремий список пам’ятних SAF-папок. Android може зберігати доступ, тому ту саму папку можна використовувати повторно без нового проходу через системний провідник.

- «Додати папку…» — надати доступ до нової кореневої папки SAF.
- «Зберегти як…» — стандартне ACTION_CREATE_DOCUMENT.
- Для деяких дій достатньо дозволу на читання, для запису потрібні читання+запис.

> **Про кореневу папку «Download» («Завантаження»)**  
> Android 11+ не дозволяє додати кореневу папку «Download» («Завантаження») через ACTION_OPEN_DOCUMENT_TREE. Для автоматичного читання папки «Download» («Завантаження») використовується окремий «Доступ до всіх файлів» або системний вибір файла як резервний спосіб.

# 17. Квота API YouTube і кеш пошуку
<a id="sec17"></a>
Екран «Квота» показує локальну оцінку: кількість пошукових викликів, орієнтовний залишок пошуків, інші одиниці API, їх орієнтовний залишок, використання кешу, кількість завдань у Черзі та день обліку квоти.

> **Це не точний баланс Google Cloud**  
> Локальна оцінка враховує тільки операції, які YTM Importer зафіксував на цьому телефоні. Інші пристрої або клієнти того самого проєкту API теж можуть витрачати квоту. Точний стан дивіться в консолі Google Cloud.

## Два різні види обмежень квоти
<a id="sec17a"></a>
Пошук має окремий денний ліміт у логіці застосунку, а 10 000 одиниць стосуються інших операцій API даних YouTube. Крім цього YouTube може тимчасово обмежити частоту запитів на запис — це обмеження частоти запитів, а не обов’язково вичерпання добової квоти.

## Кеш пошуку
<a id="sec17b"></a>
Кеш пошуку зберігає результати пошуку, щоб повторно не витрачати запит `search.list` для того самого треку. У розділі «Сервіс» можна переглянути статистику, видалити тільки прострочені записи або очистити весь кеш.

> **Що не видаляється при очищенні кешу**  
> Історія, Черга незавершених операцій та YouTube/YTM плейлисти не змінюються. Але наступний пошук очищених треків знову витрачатиме квоту.

# 18. Сервіс, діагностика й оновлення
<a id="sec18"></a>
## Швидкий старт і приватність
<a id="sec18a"></a>
Сервіс містить вбудовану коротку довідку з 4 кроків та окремий екран приватності з поясненням авторизації Google через OAuth, локальних даних, резервних копій і незалежного статусу застосунку.

## Діагностика
<a id="sec18b"></a>
Діагностика збирає стан акаунта, поточного імпорту, локальної оцінки квоти, кешу пошуку, Історії та Черги незавершених операцій. Звіт можна зберегти або поділитися ним як TXT.

> **Діагностика маскує і не включає секрети**  
> Звіт не містить токена доступу OAuth, пароля Google або ключів підпису. Електронна адреса та ID каналу передаються замаскованими.

## Про застосунок і історія змін
<a id="sec18c"></a>
Екран «Про YTM Importer» показує версію, можливості та принципи. «Історія змін» читає CHANGELOG.md, вбудований у APK під час збірки, і показує найновіші релізи першими.

## Вбудований модуль оновлення
<a id="sec18d"></a>
1. Натиснути «Перевірити оновлення».
2. Якщо є нова стабільна версія — явно натиснути «Завантажити APK».
3. YTM Importer перевіряє SHA-256 завантаженого APK.
4. Після успішної перевірки стає доступна «Встановити».
5. Якщо Android не дозволяє інсталяцію з цього джерела, відкрийте системний дозвіл, поверніться й натисніть «Встановити» ще раз.

> **Джерело оновлень**  
> Модуль оновлення перевіряє офіційний реліз GitHub репозиторію faric-ua/YTM. APK не завантажується без явного натискання.

# 19. Теми оформлення
<a id="sec19"></a>
*Реальний екран Меню. Тут знаходиться Тема, Синхронізація всіх, Центр відновлення, Дані і Сервіс.*

Меню → «Тема». Доступні три вбудовані теми з системними назвами: `Neon Dark`, `Blue Dark` і `Green Dark`. Вибір спочатку показується як попередній перегляд; активна тема зміниться тільки після «Застосувати».

- `Neon Dark` — основний контрастний неоновий акцент.
- `Blue Dark` — синя спокійніша палітра.
- `Green Dark` — зелена альтернативна палітра.

Попередній перегляд показує службові кольори: поверхня/акцент, успіх, попередження, небезпека, дублікат. Тема зберігається на пристрої.

# 20. Приватність і безпека даних
<a id="sec20"></a>
| Дані | Де можуть зберігатися / використовуватися |
| --- | --- |
| Токен доступу OAuth | Використовується для сеансу API, але не входить до Проєкту YTM, звіту діагностики або повної резервної копії. |
| Електронна адреса Google / ID каналу | Можуть входити до повної резервної копії та локального стану; у звіті діагностики вони маскуються. |
| Історія / Черга / кеш пошуку / поточний робочий простір | Зберігаються локально на телефоні та входять до повної резервної копії. |
| Проєкт YTM | Містить робочий плейлист, треки та точні `videoId` і пов’язані дані, але не токен OAuth. |
| системне меню «Поділитися» Android | YTM Importer сам не завантажує файл на власний сервер; після вибору іншого застосунку передача залежить від нього. |

## Що може бути чутливим у повній резервній копії
<a id="sec20a"></a>
Повна локальна копія може містити електронну адресу, ID каналу, назви плейлистів, Історію, Чергу, поточний робочий список, кеш пошуку та кеш знімків за URL. Надсилайте такий файл тільки туди, де довіряєте одержувачу.

> **Незалежний інструмент**  
> YTM Importer не є офіційним застосунком Google або YouTube і не має власного сервера, реклами чи вбудованої аналітики.
