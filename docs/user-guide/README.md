## Мовне правило

Основний текст документації ведеться українською. Назви продуктів (YouTube, Google, Android), загальноприйняті абревіатури (YTM, API, URL, JSON, APK, SAF, OAuth тощо) та точні системні ідентифікатори на кшталт `videoId`, `playlistId`, `manifest.json` залишаються без перекручення, якщо це допомагає користувачу впізнати їх у застосунку або файлі.

## Правило безпеки

Поворот екрана, натискання «Назад», повторне відкриття Історії, Черги, Центру відновлення або екрана попереднього перегляду **не повинні самі запускати** пошук, віддалений запис, відновлення, відкат, видалення чи іншу зміну даних.
