# YTM Importer v0.10.0 — Планувальник квоти + Черга

## Основна мета

Версія додає два механізми:

1. **Quota Planner (планувальник квоти)** — локально оцінює використані API-виклики.
2. **Pending Queue (черга)** — якщо запис плейлиста зупинився через quota error
   (помилку квоти), недодані треки зберігаються і можуть бути продовжені пізніше.

## Реалізовано

- локальний лічильник `search.list`;
- локальна оцінка загальної квоти;
- cache hits (попадання в кеш);
- попередній Search plan (план пошуку);
- попередня оцінка write quota перед створенням/додаванням;
- точне розпізнавання YouTube API error reason;
- збереження playlist ID;
- збереження Google email;
- збереження YouTube Channel ID;
- збереження невиконаних videoId;
- автоматична зупинка при quotaExceeded;
- вже додані треки залишаються в YouTube/YTM;
- невиконані треки отримують статус `PENDING`;
- кнопка `Черга`;
- Resume (продовження) завдання;
- перевірка акаунта/каналу перед Resume;
- локальне збереження черги між перезапусками застосунку;
- Termux script для завантаження останнього APK з GitHub Actions.

## Важливо

Лічильник квоти — **локальна оцінка**, а не офіційний точний залишок Google.
Один API project (проєкт API) може використовуватись іншими пристроями/клієнтами.

Google Cloud Console залишається джерелом точного usage (використання).
