# YTM Importer v1.0.0-rc2

## Поточний фокус

Так — ми поки працюємо насамперед із функціональністю.

Візуальні проблеми типу:
- щільні кнопки;
- неідеальні відступи;
- застарілий вигляд;
- Material 3;
- красивіші окремі екрани

залишаємо на після `v1.0.0`.

Зараз UI виправляється тільки якщо він реально заважає виконати дію.

## Нове в RC2

### History navigation

`History → Playlist → Назад → History`

Більше не потрібно закривати History і відкривати її заново,
щоб перейти до іншого запису.

### YTM Project

У `History → Playlist → Дії`:

- `Зберегти YTM Project`
- `Поділитися YTM Project`

Файл `.ytm.json` можна знову завантажити через:

`1. Файл`

Він відновлює точні YouTube videoId та вибрані заміни.

Якщо всі videoId присутні, можна одразу натиснути:

`4. Створити`

без повторного Search.

### Share

Для Share YTM Importer не має власної хмари.
Файл передається через стандартний Android Share.
