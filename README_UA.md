# YTM Importer v1.4.6

Реліз уніфікації кнопок і сервісного екрану.

## Правило кнопок

- `Скасувати / Підтвердити` у звичайних confirmation dialogs залишаються
  простими текстовими діями — так вони займають менше місця.
- Якщо є 3 дії, дві основні показуються як кнопки, а `Закрити / Назад`
  стає простим текстом під ними.
- Quota лишає окремий layout: Google Cloud зверху, Queue + Close знизу.

## Сервіс

Старий великий popup `Сервіс` замінено на окремий `ServiceActivity` зі
стилізованими картками.

Q-001 залишається OPEN.
