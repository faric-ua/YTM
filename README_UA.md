# YTM Importer v0.15.2

Версія стабілізації перед Release Candidate v1.0.

## Нове

- адаптивна іконка застосунку;
- `Сервіс → Про програму`;
- зрозуміліші повідомлення про помилки;
- regression checklist;
- невелике очищення старого коду.

## Поточний функціонал

CSV/TXT/текст → пошук → ручна перевірка → новий/існуючий playlist → duplicate check → quota-safe write → Queue/Resume → History → Export/Backup → Diagnostics.

## v0.15.1 hotfix

У v0.15.0 GitHub Actions падав під час Kotlin-компіляції через відсутній
згенерований `BuildConfig`. У v0.15.1 генерацію `BuildConfig` явно увімкнено
в `app/build.gradle.kts`.

## v0.15.2 — ручні заміни

При вставці YouTube/YTM URL застосунок тепер отримує реальну назву відео
та канал. У списку фактична заміна показується основним рядком, а початковий
трек залишається нижче як `Заміна для: ...`.

Оригінальний запис не перезаписується, щоб History і журнал замін могли
зберігати зв'язок `Оригінал → Заміна`.
