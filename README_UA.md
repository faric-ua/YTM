# YTM Importer v0.11.0

Android-застосунок для імпорту треків у YouTube / YouTube Music.

## Нове: Історія (History)

У верхньому горизонтальному меню є компактна кнопка:

`Історія`

Вона не забирає вертикальний простір у списку треків.

Для кожної write-операції (операції запису) локально зберігаються:

- дата;
- джерело;
- назва плейлиста;
- playlist ID;
- Google account;
- YouTube/YTM channel;
- тип: новий / існуючий;
- додані / помилки / pending / skipped / missing;
- статус операції;
- дані проблемних та вручну замінених треків.

Із запису історії можна:

- відкрити плейлист у YTM;
- скопіювати посилання;
- скопіювати підсумок;
- скопіювати історичний журнал проблем;
- видалити локальний запис.

Історія зберігає до 100 останніх операцій.

## Зв'язок із Чергою

Якщо виникає quotaExceeded:

`History → очікує квоти`

і паралельно завдання залишається в:

`Черга → Продовжити`

Після Resume той самий History Entry оновлюється, а не створюється заново.
