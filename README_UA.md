# YTM Importer v1.4.8

Реліз виправлення меж custom dialogs.

## Що виправлено

На довгих вікнах `Квота` і `Заміни / проблемні треки` верх картки міг
обрізатися. Причина була у вертикальному центруванні самої високої картки
всередині ScrollView.

Тепер усі custom dialogs через UiChrome мають один safe viewport:

- враховується status bar;
- враховується display cutout;
- враховується нижня navigation / gesture area;
- короткі вікна лишаються по центру;
- довгі починаються з видимого верху і скроляться.

Fix автоматично поширюється на Menu / Message / Record dialogs.

Q-001 залишається OPEN.
