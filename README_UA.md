# YTM Importer v0.12.0

## Нове: перевірка дублікатів

Коли вибрано:

`4. Створити → Додати до існуючого плейлиста`

застосунок спочатку читає videoId треків у цільовому плейлисті.

Якщо знайдено дублікати:

```text
Знайдено дублікатів: 7

Уже є в плейлисті: 5
Повтори всередині імпорту: 2
Нових треків: 13

[Скасувати]
[Додати все одно]
[Пропустити дублікати]
```

### Рекомендований режим

`Пропустити дублікати`

Тоді:

- для них не робиться `playlistItems.insert`;
- статус у списку: `⧉ дублікат`;
- вони записуються в History;
- вони потрапляють у журнал проблем/замін;
- програма показує оцінку заощадженої write quota.

### Як порівнюємо

Тільки exact YouTube `videoId`.

Не назва, не артист і не відсоток збігу.

Тому Extended Mix та Original Mix можуть залишатися двома різними треками,
якщо YouTube має для них різні videoId.
